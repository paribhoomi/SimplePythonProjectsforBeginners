# Python Practice Projects

This repository contains a collection of small Python programs created while learning and practicing core programming concepts.

## 📁 Files Included

* `API.py` – Basic API-related practice
* `contacts` – Contact management data/file
* `expenses.json` – Data file for expense tracking
* `expensetracker.py` – Simple expense tracker application
* `game.py` – Python game logic
* `generator.py` – Generator functions practice
* `logger.py` – Logging implementation
* `num.py` – Number-based operations
* `practice.py` – General Python practice
* `student.py` – Student data handling
* `todo.py` – To-do list application
* `wordcount.py` – Word count script

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone <your-repo-url>
cd python_practice
```

### 2. Create a virtual environment (optional but recommended)

```bash
python3 -m venv venv
source venv/bin/activate   # On macOS/Linux
```

### 3. Run any script

```bash
python filename.py
```

Example:

```bash
python wordcount.py
```

## 🛠 Requirements

If you add dependencies, generate a requirements file:

```bash
pip freeze > requirements.txt
```

Install dependencies:

```bash
pip install -r requirements.txt
```
